How to give feedback

  1. Open each full-screen and scroll it. The switcher at the bottom moves between them.
  2. Hover the small mark after a value (? or §) — that is provenance. Hover the i beside a property name — that is the explanation. They are deliberately different targets.
  3. Look at ضریب انبساط حرارتی and مقاومت ضربه ایزود — those are the empty-value invitations.
  4. Narrow the window below 900px. The mobile layout is a different layout, not a squeezed one.
  5. Tell me which one, and what you would take from the others. Mixing is expected — these are directions, not finished products.

What is identical in all four, on purpose

Content
Real LDPE values from the seeded database. Nothing invented.
The one "cited" value
Vicat is marked as sourced and its popover says DESIGN SAMPLE. No real citation exists yet — all 109 seeded values are unsourced, and inventing a page number even in a mock is the failure this project exists to prevent (R5).
Two affordances
ⓘ on the property name = what is this. Mark on the value = who says so (D4).
Colour
In E every hue has exactly one job — teal is measurement, sage is a satisfied citation, grey is a missing one, clay is something you can do, ochre is reserved for warnings and therefore absent from a healthy page. On Learn a second, separate ramp encodes temperature; it never borrows the status palette.
Numerals
Latin everywhere, tabular, in LTR islands inside RTL prose (D18, R6).
Type
Estedad for Persian in all four (D17). Latin display faces differ by treatment.
Structure
One scrolling datasheet with a sticky section rail; Learn is a separate route reached by one button; each section ends with a bridge to its tool (D23, R28).
Empty values
Rendered as an invitation, never hidden and never a bare dash (D11, D22).
